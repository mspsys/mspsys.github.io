MaxLife Comments

Secure image uploads, self-deletion, and link control for WordPress comments.

Key Features

  • Image Uploads: Allows commenters to attach images, held automatically for admin moderation.
  • Comment Self-Deletion: Gives commenters a 12-hour window to delete their own comments.
  • Link Control: Strips unauthorized URLs from commenter text while keeping links clickable for authenticated post authors.
  • Bilingual Support: Built-in English and Korean interface strings.
  • Zero Bloat: No complex settings pages, database overhead, or jQuery dependencies.
