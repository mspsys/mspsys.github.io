MaxLife Comments

v1.0.0 · Comments & Interaction댓글 · 소통

Secure image uploads, self-deletion, and link control for WordPress comments.워드프레스 댓글을 위한 안전한 이미지 첨부, 작성자 삭제, 링크 관리.

Download다운로드 maxlife-comments-1.0.0.zip GitHub repositoryGitHub 저장소

Key features주요 기능

  • Image uploads이미지 첨부: Commenters attach images; every comment with an image waits for your approval.댓글에 이미지를 첨부할 수 있고, 이미지가 있는 댓글은 모두 관리자 승인 후 공개됩니다.
  • Comment self-deletion작성자 삭제: Commenters get a 12-hour window to delete their own comment.작성자는 12시간 동안 자기 댓글을 삭제할 수 있습니다.
  • Link control링크 관리: Links stay plain text for visitors and are clickable only in your own comments.방문자 댓글의 주소는 일반 글자로, 관리자 댓글의 주소만 링크로 표시됩니다.
  • Bilingual한국어·영어: Built-in English and Korean interface strings, chosen by the browser.브라우저 언어에 따라 영어·한국어 화면이 자동으로 표시됩니다.
  • Zero bloat가벼움: No settings page, no extra database tables, no jQuery.설정 페이지도, 추가 데이터베이스 테이블도, jQuery도 없습니다.
