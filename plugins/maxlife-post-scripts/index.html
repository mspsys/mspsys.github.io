MaxLife Post Scripts

v1.1.0 · Per-post CSS & JavaScript글별 CSS · JavaScript

Per-post custom CSS, JavaScript, and external CDN scripts — the easiest way to build interactive posts in the Classic Editor.글마다 CSS, JavaScript, 외부 CDN 스크립트 — 클래식 에디터에서 인터랙티브 글을 만드는 가장 쉬운 방법.

Download다운로드 maxlife-post-scripts-1.1.0.zip GitHub repositoryGitHub 저장소

Key features주요 기능

  • VS Code-style editorVS Code 스타일 에디터: Dedicated code boxes for post-specific CSS and JavaScript, with line numbers and syntax colors.글마다 CSS와 JavaScript를 넣는 전용 코드 상자 — 줄 번호와 문법 색상 포함.
  • External CDN supportCDN 라이브러리: Include libraries like Chart.js or D3 by URL, only on the posts that need them.Chart.js, D3 같은 라이브러리를 주소로 추가 — 필요한 글에서만 불러옵니다.
  • Ordered loading순서대로 로드: External scripts load in the order you list them, before the post’s own JavaScript.외부 스크립트가 적은 순서대로, 글의 JavaScript보다 먼저 로드됩니다.
  • Seamless migration그대로 이어받기: Takes over Simple CSS’s per-post CSS — nothing to rewrite or copy over.Simple CSS의 글별 CSS를 그대로 이어받습니다 — 다시 쓰거나 옮길 것이 없습니다.
  • Lightweight가벼움: No jQuery, and nothing extra on pages that don’t use it.jQuery 없음, 사용하지 않는 페이지엔 아무것도 추가되지 않습니다.
