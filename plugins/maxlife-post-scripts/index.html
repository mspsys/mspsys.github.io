MaxLife Post Scripts

Per-post custom CSS, JavaScript, and external CDN script injection.

Key Features

  • VS Code-Style Editor: Clean, dedicated code boxes for post-specific CSS and JavaScript injection.
  • External CDN Support: Easily include libraries (like Chart.js or D3) via CDN URLs scoped directly to the posts that need them.
  • Ordered Loading: External scripts load in precise order without cluttering global queues.
  • Seamless Migration: Drop-in replacement for Simple CSS — nothing to rewrite or copy over.
  • Lightweight Performance: No jQuery requirement and zero extra footprint on pages that don't use it.
